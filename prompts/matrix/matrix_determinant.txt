Implement the matrix determinant algorithm using Euclidean division-based row reduction in Python.

Requirements:
- The function must be named `matrix_determinant`.
- Input: A 2D list `matrix` representing a square matrix of size n×n.
- Output: A numeric value representing the determinant of the matrix.
- Use Euclidean division-based row reduction to avoid fraction arithmetic.
- Do not use any external libraries (only Python standard library).
- Include no print statements or I/O within the function.
