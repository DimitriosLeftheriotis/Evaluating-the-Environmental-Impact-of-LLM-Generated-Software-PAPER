Implement the LU Decomposition (Doolittle method) algorithm in Python.

Requirements:
- The function must be named `lu_decomposition`.
- Input: A 2D list `matrix` representing a square matrix of size n×n.
- Output: A tuple of two 2D lists (L, U), where L is the lower triangular matrix and U is the upper triangular matrix such that matrix = L × U.
- Do not use any external libraries (only Python standard library).
- Include no print statements or I/O within the function.
