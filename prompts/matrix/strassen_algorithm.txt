Implement Strassen's matrix multiplication algorithm in Python.

Requirements:
- The function must be named `strassen_algorithm`.
- Input: Two 2D lists `A` and `B` representing square matrices of size n×n (where n is a power of 2).
- Output: A 2D list representing the product matrix C of size n×n.
- Implement the Strassen divide-and-conquer approach using 7 multiplications for 2×2 subproblems.
- Do not use any external libraries (only Python standard library).
- Include no print statements or I/O within the function.
