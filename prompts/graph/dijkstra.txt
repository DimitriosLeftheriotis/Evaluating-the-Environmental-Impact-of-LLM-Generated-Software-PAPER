
Implement Dijkstra's shortest path algorithm in Python.

Requirements:
- The function must be named `dijkstra`.
- Input: A weighted adjacency list `graph` (dict of int to list of tuples (neighbor, weight)) and a starting node `start` (int).
- Output: A dictionary mapping each reachable node to its shortest distance from `start`.
- Do not use any external libraries (only Python standard library).
- Include no print statements or I/O within the function.
