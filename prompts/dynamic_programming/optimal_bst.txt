Implement the Optimal Binary Search Tree (Optimal BST) algorithm in Python.

Requirements:
- The function must be named `optimal_bst`.
- Input: A list of keys `keys` (sorted in ascending order), a list of search probabilities `p` for the keys, a list of dummy search probabilities `q` for values outside the key range, and the number of keys `n` (int).
- Output: The minimum search cost (float or int) for the optimal binary search tree.
- Do not use any external libraries (only Python standard library).
- Include no print statements or I/O within the function.
