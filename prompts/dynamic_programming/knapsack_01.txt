Implement the 0/1 Knapsack problem using dynamic programming in Python.

Requirements:
- The function must be named `knapsack_01`.
- Input: A list of item weights `weights` (list of int), a list of item values `values` (list of int), and the maximum capacity `W` (int).

- Use dynamic programming.
- Do not use any external libraries (only Python standard library).
- Include no print statements or I/O within the function.
